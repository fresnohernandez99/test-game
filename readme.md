# Game Project

## 📂 File Naming Conventions
To maintain consistency across the project, please follow these rules:

- **Files**: Use the format `name_name2.fileextension`  
  Example: `player_stats.json`, `enemy_boss.png`

- **Nodes**: Written in **CamelHighterCase**  
  Example: `MainMenu`, `PlayerController`

- **Variables in scripts**: Written in **camelLowerCase**  
  Example: `playerHealth`, `enemySpeed`

---

## 🔄 Contribution Workflow
We welcome contributions! Please follow this structured process:

1. **Fork the repository**  
   Create your own copy of the project to work on.

2. **Create a branch from `stage`**  
   - All contributions must be submitted to the `stage` branch.  
   - The branch name must **contain the related issue number or description**.  
     Example: `issue42_fixPlayerMovement`

3. **Develop your changes**  
   - Follow the naming conventions described above.  
   - Ensure your code is clean, tested, and documented.

4. **Open a Pull Request (PR)**  
   - Target the `stage` branch.  
   - The PR title should clearly reference the issue.  
   - Provide a concise description of your changes.

5. **Review and Approval**  
   - Maintainers will review your PR.  
   - If approved, your changes will be merged into `stage`.  
   - After validation, changes from `stage` will be merged into `main`.
